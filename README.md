# 苔原远征 · 长夜行旅

原生 HTML / CSS / JavaScript 单人自走棋，无构建步骤或第三方运行依赖。公开入口：https://chess.jyork.de/

## 本地启动

```sh
python3 -m http.server 8879 --bind 127.0.0.1
```

打开 http://127.0.0.1:8879/ 。美术和声音均为本地资源，不调用外部接口。

## 三章远征

- 每局生成三章地图，每章九层、三条分支，共 69 个地图节点；实际路线经过 27 站。节点与连接随种子变化，只能沿相连道路前进。
- 战斗节点包括遭遇、精英与每章首领；敌方阵容、站位、星级、词缀和章节强度会改变。新生成地图第一章普通战最多四人、精英最多五人；第二章把人数与星级提升错开。地图提前展示首领特点，未知事件抵达后揭晓。
- 营地三选一：恢复 26 远征生命、精制一件装备（加成提高 60%）、获得 5 金币。
- 游商出售有限的装备、遗物与恢复补给；可买多件或直接离开。六类事件提供明确的收益、成本和风险，宝箱可选随机珍藏或固定 7 金币。
- 普通战斗胜利有 22% 概率掉落装备，自动进入行囊。精英和前两章首领胜利提供三选一遗物，也可放弃。宝箱开启为 55% 遗物、45% 装备。
- 地图、商品、事件随机结果和掉落在当前远征内固定，刷新页面不会重抽。

## 伙伴与损耗

伙伴战后全部恢复生命并保留星级、装备、阵型。单场阵亡不会删除伙伴，但会产生远征损耗：胜利时每名阵亡损失 2 远征生命、上限 8；险境有阵亡时另加 1。行军口粮与血契遗物会改变损耗。

普通与精英战败损失远征生命，第一至第三章分别获得 3 / 4 / 5 金币撤退补给；下一场战斗有两次免费刷新，然后继续前进，不能重试同一节点。每章首领战败或远征生命归零，本局结束。远征生命不会随战斗结束自动恢复。

## 阵容与经济

- 二十二位可招募伙伴，林地、星辉、月影、潮汐、余烬五种开局与悠游、冒险、险境三档难度。每个开局给出本阵营两位伙伴，起手价值一致，首批酒馆必有一位同阵营伙伴。悠游敌人强度 -15%，险境 +8% 且损耗更高；界面显示的百分比由敌人强度倍率直接计算，不会与规则脱节。
- 六列六排棋盘，我方后三排布阵；人口从 3 扩至 6，备战席 8 格。同种同星三个自动合成，最高三星；重复角色不重复计入羁绊。
- 五个阵营有 2 / 3 种伙伴效果，守卫、游侠、法师、辅助、刺客都有两种伙伴职业羁绊；每个阵营至少四位可选，双阵营伙伴连接不同队伍。嘲讽、治疗、净化、群体法术、控制、突袭和法力支援实际影响战斗。刺客开场潜伏 1.5 秒后切入，落地后 1 秒不可被选中，范围伤害仍可命中；敌我同规则。
- 六种基础装备，各有精制版本；每位伙伴携带一件，可卸下或交换。
- 胜利基础收入第一至第三章分别 5 / 6 / 7 金币；每 10 存款提供 1 利息、最多 2。三连胜起 +1，精英 +3、首领 +5，部分遗物另有收益。
- 每次进入战斗节点获得一次免费刷新，前一战失利则为两次；非战斗节点不发免费刷新。每批酒馆有一个成长位，优先补齐已有的两张同种一星伙伴，否则提供一个已有伙伴。酒馆按阵营规模补偿出现权重：成员较少的阵营每缺一位成员，其伙伴多进入一次牌池，五个阵营的出现率因此持平。酒馆可锁定，招募、付费刷新、升星和扩容仍需管理金币。
- 战斗 50 秒加时，伤害提高 60%、治疗减半；80 秒未胜则失败。

## 操作与存档

招募后点击伙伴再点棋格，或拖动换位；「整队」可自动上阵。空格开战 / 暂停，R 刷新，M 静音。支持三档速度、音效、可选背景音乐和减少动画。暂停时保留清晰棋盘，选中伙伴可查看交战目标箭头、嘲讽来源及控制 / 防护状态。

桌面内容区至少 900 × 600 时，棋盘、备战席、酒馆保持一屏。手机采用纵向布局，地图可横向滑动。

准备、战斗、地图及服务节点自动保存。战斗约每秒保存，刷新后暂停等待继续。v3 使用独立的 `tundra-expedition-v3` 和 `tundra-records-v3`；旧 v1 / v2 存档保留，但不导入新地图规则，需要开始新远征。v2 声音偏好继续沿用。存档属于当前浏览器与域名，清除网站数据会删除进度。

## 战斗洞察与准备

- 战报先展示首位阵亡、守卫平均存活和敌方剩余人数，再展示按实际记录生成的调整建议。
- 可切换伤害、有效治疗、护盾吸收、实际生命承伤四项，以及敌我两侧。每位伙伴列出存活时间与施法次数。
- 承伤类型分别记录物理、魔法、真实伤害，不包含护盾吸收；阵亡来源为最后一击，建议不宣称它是全部失败原因。
- 守卫存活取守卫职业的平均值，活到结束的伙伴按本场时长计；没有守卫显示未上阵。
- 伙伴面板可切换普攻射程与技能预览。指向型技能可点击敌方棋格选择示意位置，技能的实际目标仍由战斗规则决定。
- 更换装备时比较当前羁绊与遗物下的有效属性，明确显示增减；点击装备即穿戴，原装备返回行囊。
- 本次沿用 v3 存档键。旧远征继续使用已生成地图，平滑后的新敌群在新远征中生成；新经济与交互用于继续的旅程。旧战斗快照可以续接，缺少详细数据的旧战报明确显示未记录，完整洞察从新战斗开始。

### 构筑组合

- 潮汐盾纹：护盾承伤回复法力，有每人 1 秒冷却；直接破盾不会触发。
- 赤月泉石：普攻暴击治疗最虚弱伙伴；赤月透镜可增加暴击率。
- 三重星铃：每位伙伴第三次施法给全队护盾；回响沙漏返还法力可加速触发。
- 满溢之杯：多余的主动治疗转护盾，最多补到目标最大生命的 25%，自然回复不触发。
- 余烬木心：每战一次，在低血量且未阵亡时生成应急护盾。精制提高收益，触发血线与持续时间不变。
- 构筑手记从行囊或旅人指南打开，显示现有组合条件与完整装备说明。新战报增加装备/遗物触发次数；旧战报不显示未记录数据。
- 新战斗中的临时护盾逐层到期，刷新不会延长既有护盾；旧战斗快照保留兼容处理。

### 有取舍的补强

商人抵达时固定生成推荐装备与核心遗物，之后换装或刷新页面不重抽商品。四象交汇可支付 10 远征生命和 4 金币，选择一枚构筑遗物；星匠旧炉可用一件备用的未精制装备与 3 金币换功能装备。都可以安全离开，遗物最多两层。

本轮新增十位伙伴及潮汐、余烬阵营，详见 [角色与羁绊设计](ROSTER22.md)。图鉴支持阵营和职业组合筛选；新远征使用 companions-22 规则，原 v3 存档仍可继续。
